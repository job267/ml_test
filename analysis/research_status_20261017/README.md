LightGCN 相对匹配初始化 MF 的总体 NDCG 约高 15.56%，图传播具有价值。已有困难采样的总体收益伴随稀疏用户退化，额外证据权重的增量未稳定复现；降低干预比例与改变候选来源也未同时解决两类表现。已有证据支持继续诊断，不支持宣称新方法已获得稳定优势。
